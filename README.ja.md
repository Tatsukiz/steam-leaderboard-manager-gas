# Steamリーダーボード管理ツール (Google Apps Script版)

> **[English README](README.md)**

SteamリーダーボードのエントリをGoogleスプレッドシート上で管理するツールです。
チート等で不正に登録されたスコアの確認・削除に加え、エントリの手動登録にも対応しています。
コマンドライン操作は不要で、シートのメニューとチェックボックスだけで運用できます。

## なぜ必要か

Steamworksパートナーサイトのリーダーボード管理機能は最小限で、運用には手が足りません。

- **一括削除ができない** — チートスコアを1件ずつ消していくのは手間がかかる
- **一覧で見比べられない** — 不正の判断材料をまとめて確認しにくい
- **一括登録ができない** — テスト用エントリやスコア補正の投入にはAPI呼び出しが必要

本ツールはこれらを、使い慣れたGoogleスプレッドシート上の
チェックボックス操作・一括登録・プロフィールリンク付き一覧として提供します。

## 機能

- **リーダーボード一覧** — ゲームに紐づくリーダーボードをID・名前・エントリ数で一覧表示
- **エントリ閲覧** — ランキングをスコア・SteamID64・プロフィールリンク付きで取得
- **エントリ削除** — チェックボックスで選択して一括削除（確認ダイアログ付き）
- **エントリ登録（単体）** — KeepBestまたはForceUpdateでスコアを登録
- **エントリ一括登録** — スプレッドシートから複数件をまとめて登録
- **日英バイリンガルUI** — メニューからワンクリックで言語切替

## 前提条件

- **パブリッシャーAPIキー** — [Steamworksパートナーサイト](https://partner.steamgames.com/) で発行できます。通常のWeb APIキーではリーダーボードの操作ができないため、必ず「パブリッシャーキー」を使用してください
- **ゲームのAppID** — Steamworksのゲームページを開いたときのURLに含まれる数字です
  （例: `https://partner.steamgames.com/apps/landing/1234567` であれば `1234567`）
- Googleアカウントとスプレッドシート（追加のツールやコマンドライン操作は不要です）

## セットアップ

### 1. スプレッドシートにスクリプトを組み込む

1. Googleスプレッドシートを**新規作成**する
2. メニューの **拡張機能 > Apps Script** を開く
3. エディタに最初から入っているコードをすべて消し、[`steam_lb_gas.js`](steam_lb_gas.js) の内容を貼り付ける
4. 保存（Ctrl+S / Cmd+S）する
5. スプレッドシートのタブに戻り、**ページを再読み込み**する
6. メニューバーに **「Steam Leaderboard」** が追加されていればOK（日本語に切替可能）

> リポジトリ内の [`appsscript.json`](appsscript.json) は、このスクリプトが要求するOAuthスコープを
> 明示するためのものです。上記のコピペ導入では**不要**です（[clasp](https://github.com/google/clasp)
> を使う場合のみ利用します）。

### 2. APIキーとAppIDを登録する

1. メニュー **Steam Leaderboard > Setup (API Key / App ID)** を実行
2. 初回はGoogleの承認画面が表示される
   - 「このアプリはGoogleで確認されていません」と出た場合は
     「詳細」>「(プロジェクト名)に移動」>「許可」の順に進む
   - 求められる権限は「スプレッドシートの編集」と「外部サービスへの接続」の2つ
3. ダイアログに従って **パブリッシャーAPIキー** と **AppID** を入力する

AppIDの確認方法は[前提条件](#前提条件)を参照してください。

登録した値はスクリプトプロパティに保存され、シートのセルには表示されません。
キーを変更したいときは、同じメニューをもう一度実行してください（空欄のままOKすると現在の値を維持します）。

### 3. 言語を日本語に切り替える

初期状態では英語UIです。日本語に切り替えるには:

メニュー **Steam Leaderboard > Language: English → 日本語** を実行（切替後は **Steamリーダーボード > 言語: 日本語 → English** で英語に戻せます）

切替後にスプレッドシートを再読み込みすると、シート名も日本語に更新されます。

## セキュリティに関する注意

> **重要**
>
> パブリッシャーAPIキーはApps Scriptのスクリプトプロパティに保存されます。**スプレッドシートの編集権限を持つ人は、拡張機能 > Apps Script > プロジェクトの設定 からキーを閲覧できます**。
>
> - 「リンクを知っている全員」での共有は**絶対にしないでください**
> - 共有は運用担当者のみに限定してください
> - キーが漏洩した場合は、Steamworksパートナーサイトで直ちに再生成してください
> - パブリッシャーAPIキーでリーダーボードのエントリの読み取り・書き込み・削除が可能です

## 使い方

### 不正エントリを削除する

1. メニュー **Steamリーダーボード > リーダーボード一覧を取得** で一覧を確認
2. メニュー **Steamリーダーボード > エントリを取得** でランキングを取得
3. 「削除する」列のチェックボックスを、削除したい行だけONにする
4. メニュー **Steamリーダーボード > チェックした行を削除** で削除実行

- 削除に成功した行は**グレー+取り消し線**になり、メモ列に削除日時が記録されます
- 最新の順位を確認するには、再度「エントリを取得」を実行してください

### エントリを登録する（1件）

メニュー **Steamリーダーボード > エントリを登録(1件)**

ダイアログに従ってリーダーボード名・SteamID64・スコアを入力します。
スコアの先頭に `!` を付けると強制上書き（ForceUpdate）になります。

### エントリを一括登録する

1. メニュー **Steamリーダーボード > 登録シートを準備** でシートを作成
2. B1セルにリーダーボード名または数値IDを入力
3. 3行目以降にSteamID64（A列）とスコア（B列）を入力
4. メニュー **Steamリーダーボード > シートから一括登録** で実行

一括登録はすべてKeepBest（既存スコアより良い場合のみ更新）で処理されます。

## コード更新方法

すでにスプレッドシートが稼働している状態でコードを更新する場合:

1. 拡張機能 > Apps Script を開く
2. 既存のコードをすべて削除し、最新の `steam_lb_gas.js` を貼り付ける
3. 保存してスプレッドシートを再読み込み

APIキー・AppID・言語設定はスクリプトプロパティに保存されているため、コードを貼り替えても設定は消えません。

## 注意事項

- **「エントリ」シートの1行目（リーダーボード名とID）を編集・削除しないでください。**
  「チェックした行を削除」がこの行を参照して削除先を判断しています。同様に、
  **「エントリ登録」シートのB1セル**も一括登録処理が参照しています
- **削除は取り消せません。** 確認ダイアログの内容を必ず確認してください
- 削除できるのは「そのリーダーボード上のエントリ」だけです。同じユーザーが再度スコアを送信すれば
  また登録されます。繰り返される場合は、クライアント側の検証強化やリーダーボードのTrusted設定
  （サーバー経由でのみ書き込みを許可する）といった根本対策が必要です
- **スコアの「良い/悪い」の判定はリーダーボードの昇順/降順設定に依存します。**
  タイムアタック（昇順）なら値が小さいほうが良いスコアです。KeepBestはこの設定に従うため、
  値が大きいスコアがスキップされることもあります
- 対象SteamIDのエントリが存在しない場合は、KeepBest / ForceUpdate のどちらでも新規作成されます
- SteamID64は17桁の数字です。セルに手動で入力・貼り付けする場合は書式を「書式なしテキスト」に
  してください。「数値」のまま貼ると末尾の桁が丸められ、別人のIDを操作する恐れがあります
  （「登録シートを準備」を使えば自動で文字列書式になります）
- KeepBest方式では入力スコアが現在の登録値より悪い場合はサイレントにスキップされます
- シートの表示は「エントリを取得」を実行した時点のスナップショットです。順位は自動更新されません

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| メニューが出ない | シートを再読み込み。それでも出ない場合はApps Script側でコードが保存されているか確認 |
| 「APIキー/AppIDが未設定です」エラー | メニューの「初期設定」を実行して登録する |
| 「APIキーが無効です(403)」エラー | パブリッシャーキーではない通常のWeb APIキーを登録している可能性あり |
| エントリが空で表示される | リーダーボード名の入力ミス（完全一致が必要）、またはエントリが本当に0件 |
| 削除後に順位が変わらない | シートは取得時点のスナップショット。再度「エントリを取得」で最新化する |
| 登録したのにスコアが反映されない | KeepBestは既存スコアより悪い場合スキップする。強制上書きは「エントリを登録(1件)」でスコアの先頭に `!` を付ける |
| SteamID64の桁が丸められる | セルの書式が「数値」になっている。「登録シートを準備」を再実行するか手動で「書式なしテキスト」に変更 |
| 承認画面で「安全ではないページ」と警告される | 自作スクリプトのため正常な挙動。「詳細」>「(プロジェクト名)に移動」>「許可」で進める |
